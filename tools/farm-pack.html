Farm pack.

A list of internet that should exist. Mapped onto this farm. Built only when we name the cell.

Honesty. We are being super honest.

  • This is not stolen work. A public pack invited people to make useful tools. We remixed the invitation. We did not take their code or their cloud stack.
  • This page is a menu. Most rows are not live products.
  • Closer is live and does a job. Add is a small card. Farm.html is thirty tiny widgets so someone can find a box they like. That tray is not thirty companies.
  • Shop is a showcase. Apparel is a lookbook. Packs sell on Gumroad. There is no public phone on this site.
  • Grok made this page from simple instructions in natural language. Danny asked for the pack on the farm, honesty reminders, and that credit. That is the whole trick.

Stack we actually use

GitHub Pages. One HTML file. gold.css. Gemini key in the browser if the tool needs a model. Gumroad if it costs money. No login. No second catalog. No Workers / Supabase / PartyKit unless Danny names them.

1. Useful micro-tools

  1. Closer. One job: messy voicemail or text → JSON lead + reply SMS. Live.
  2. Anti-bloat Add. Two numbers, a sum, copy. No React blob. Live.
  3. Variety tray. Thirty tiny tools on one page so people can poke until something fits. Live.
  4. Miami paste. Drop a permit or complaint paragraph into the same closer JSON. No live county API until we name it. Not built.

2. AI as utility, not spam

  1. Forge. Chat, grounded search, JSON, image, TTS. Key stays here. Live.
  2. Studio. Talk until a page appears. Export HTML. Live.
  3. Grounded take. Paste a headline. Get source, counter, two links. Not a content mill. Not built as its own page — Forge grounding can do it.
  4. Bookmarklet. Select text anywhere, open closer with that text. Not built.

3. Keep human knowledge

  1. Lens. db.html + library.json is the public list of what exists. Not a second database. Live.
  2. CodeShelf. Snapshot of the packs. Museum, not a new cashier. Live.
  3. Blog. Slow notes. No infinite feed. Live.

4. Still gates, not built

  1. HVAC landing that posts into closer. Only after closer is a keep.
  2. Ghost Turk juice — same rules, clearer HUD. Play is already live.
  3. Studio preset that dumps VOIDD chrome.
  4. Simple email on call.html — mailto only, when Danny pastes the address.

How to use the pack

Pick the row that annoys you because it does not exist yet. Say that row. We ship one file. Then keep / cut / change / kill. Do not run the whole list in one night.
