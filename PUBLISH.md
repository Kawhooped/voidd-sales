# How a new app lands

1. You send Grok the file (zip) + price.
2. Grok creates or updates the DIGITAL product on Wix Void_Works.
3. You attach the file in Wix dashboard if API cannot take the zip.
4. Grok adds one row to api/products.json. Showcase buy button uses wixPath.
5. Site must be published before the product page is public.
