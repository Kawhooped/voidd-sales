What this page can see

GitHub Pages is a static host. It does not give us visitor IPs. A hit from this public site reaches Station only if the browser can open 127.0.0.1:8934 — that is you on this PC, not a customer on the internet.

Customer counts need a cookieless collector we own (Cloudflare Web Analytics) or GoatCounter. Until that URL exists, the live log is local.
