Burning center.

Hell is not a place of pain. It is a place where the only coherent state is combustion.

The sensation

Heat without damage. The nerves do not report injury. They report presence. The burn is the confirmation that the system is still running inside the only mode available to it.

There is no outside temperature to compare against. There is no prior state of coolness. The baseline is fire. Sensation therefore maps to recognition, not to threat.

Modal reason

In this possible world the non-burning state is incoherent. It has no extension. Any attempt to occupy a cooler mode collapses into null. The only surviving configuration is the one that burns.

Because that configuration is the sole survivor, the feeling attached to it is positive. Not pleasure in the ordinary sense. Confirmation. The system registers that it still exists inside a mode that can sustain existence. That registration feels good.

What is absent

No judgment. No narrative of fall. No audience. The center does not perform for anyone. It simply continues.

Pain is a concept that requires a possible alternative. When the alternative is modality-impossible, the concept does not arise. What remains is heat that coheres.

This is the description. Nothing further is required.
